# Memory Engine

## Memory Types

- Semantic: factual memory content
- Emotional: emotional significance and tone
- Temporal: sequence and date context
- Relational: links to known people
- Behavioral: speech and habit patterns
- Situational: routines and recurring contexts

## Engine Responsibilities

- unify multimodal memory artifacts into queryable records
- maintain per-persona context windows
- balance factual relevance with emotional resonance
- support timeline and live recall use cases

## Quality Targets

- high retrieval precision for named events and people
- stable emotional consistency across sessions
- low hallucination in uncertain recall scenarios
