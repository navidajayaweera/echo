# Team Onboarding

## Read Order for New Contributors

1. `docs/README.md`
2. `docs/00-product/product-vision.md`
3. `docs/00-product/core-features.md`
4. `docs/01-architecture/system-overview.md`
5. `docs/14-decisions/` latest files

## Working Rules

- start every feature from persona-first assumptions
- confirm safety and transparency requirements early
- avoid provider-specific coupling in UI
- update docs when architecture or flows change

## Definition of Done

- implementation complete
- tests and validation done
- docs updated (feature + architecture + decision)
- unresolved risks documented
