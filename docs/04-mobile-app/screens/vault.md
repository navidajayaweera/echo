# Vault Screen

Purpose: Searchable human memory archive, not a generic media gallery.

## Categories

- Photos
- Videos
- Voice Notes
- Journals
- Letters
- Conversations
- Milestones
- Relationships

## Core Behaviors

- persona-scoped filtering
- semantic search
- timeline grouping
- emotional-tag filtering

## Dependencies

- storage APIs
- memory metadata index
- embeddings pipeline status

## Must Not Break

- capture and ingest reliability
- memory ownership integrity
