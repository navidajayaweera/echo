# Avatar Experience

## Goal

Deliver a calm, emotionally grounded visual presence that supports memory continuity without deceptive realism claims.

## States

- idle ambient state
- listening state
- speaking state
- memory recall highlight state
- reflection cooldown state

## Behavior Rules

- visual transitions should be smooth and non-jarring
- emotional cues should remain subtle
- spoken content and captions must stay synchronized
- explicit AI disclosure remains visible in session context

## Memory Recall Presentation

- surface recalled artifact card with source and date when available
- avoid overstating uncertain memories
- allow user to dismiss or pin memory card
