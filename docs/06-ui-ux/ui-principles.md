# UI/UX Principles

## Visual Direction

- cinematic dark aesthetic
- soft gradients and ambient glow
- spacious composition and calm pacing
- emotionally weighted transitions

## Product Feel

- sacred memory archive, not social feed
- intimate presence, not assistant utility panel
- gentle guidance, not aggressive engagement loops

## Interaction Rules

- persona-first context on all major surfaces
- memory artifacts presented with narrative framing
- transitions should feel reflective and human

## Accessibility

- high text contrast on dark backgrounds
- caption-first support in voice/avatar modes
- reduced-motion compatibility
