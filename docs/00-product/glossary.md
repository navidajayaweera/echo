# Glossary

**Persona**  
A preserved identity composed of memories, behavioral traits, speech style, and relationship context.

**Profile**  
The authenticated account owner who creates and manages personas.

**Presence**  
The live conversational experience (text, voice, or avatar) with a selected persona.

**Vault**  
The long-term memory repository containing media, journals, transcripts, and timeline events.

**Memory Recall**  
Runtime retrieval of relevant memory fragments during conversation.

**Emotional Continuity**  
A feeling of ongoing relational connection enabled by memory-grounded interaction.

**Ethical Mode**  
Policy configuration that defines safety boundaries for a persona's behavior.

**Relationship Graph**  
Structured links between people in a persona's world (family, friends, caregivers).

**Beyond Presence**  
Avatar and real-time emotional presentation layer for cinematic face-to-face interaction.

**Reflection Mode**  
A slower, deeper conversational mode focused on emotional processing and memory integration.
