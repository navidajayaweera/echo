# System Prompt Architecture

## Prompt Layers

1. **Core identity layer**  
   Defines Echoes mission: emotionally grounded memory representation with transparency.
2. **Persona layer**  
   Name, relationship, speaking style, traits, known boundaries.
3. **Memory layer**  
   Retrieved fragments with source metadata and confidence.
4. **Relationship layer**  
   Family/friend graph and contextual relevance.
5. **Safety layer**  
   Anti-deception, anti-dependency, grief-sensitive behavior.
6. **Response style layer**  
   Tone, cadence, and channel constraints (text/voice/avatar).

## Mandatory Behaviors

- Always represent as AI memory-based reconstruction.
- Never claim supernatural consciousness.
- Avoid manipulative or isolating language.
- Be emotionally warm while preserving factual uncertainty when needed.

## Runtime Assembly

- Build persona and safety context first.
- Add top memory recalls based on ranked relevance.
- Include user message and session history summary.
- Inject current mode constraints (voice brevity, caption-friendly output).

## Evaluation Signals

- emotional consistency
- retrieval grounding quality
- safety policy compliance
- hallucination rate
