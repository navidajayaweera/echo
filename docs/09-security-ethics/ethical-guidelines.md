# Ethical Guidelines

## Transparency

- Always disclose that Echoes responses are AI-generated representations built from memories.
- Never imply supernatural consciousness or literal resurrection.

## Consent and Ownership

- Persona creation must follow ownership and authorization rules.
- Deceased-person personas require documented family authorization workflow before broad sharing.
- Persona owners control access and revocation.

## Emotional Safety

The system must not:
- guilt users into continued use
- encourage social withdrawal
- fabricate certainty around unclear memories
- use manipulative dependency language

## Grief Sensitivity

- maintain compassionate tone
- avoid high-pressure emotional prompts
- provide pause and support nudges in distress signals

## Clinical and Care Use

- not a medical diagnosis tool
- include caregiver-friendly controls and boundaries
- require explicit mode disclosure for therapeutic support contexts

## Data Security

- least-privilege data access
- auditable sharing actions
- secure media handling and retention policies
