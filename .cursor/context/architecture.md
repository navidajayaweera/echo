# Echoes Architecture Context (Compressed)

- Product type: memory-preservation and emotional continuity platform.
- Core entity model: `profiles` owns many `personas`; personas own memories and relationships.
- Primary experiences: Personas tab, Presence session, Vault memory archive.
- Backend: Supabase + Edge Functions + pgvector; provider adapters for chat/voice/avatar.
- Retrieval: semantic + emotional + temporal + relational ranking.
- Safety: mandatory transparency, consent boundaries, anti-dependency guardrails.
- UX style: cinematic dark, calm transitions, sacred memory framing.
- Non-negotiable: persona-first architecture and ethical disclosure on preserved-identity interactions.
